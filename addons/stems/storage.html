While downloading, the temporary file is ytbm-stems/htdemucs-fp16.onnx.part. It is replaced by the verified model when installation completes.

  
Chrome manages the backing files inside your browser profile; the model is not in the unpacked extension folder or your Downloads folder. To identify the exact profile folder, open chrome://version in this same Chrome window and read Profile Path.

  
Reloading or disabling/re-enabling this installation should retain the model. Removing the extension can delete its private storage. The in-app Uninstall stems command deliberately erases the model.

  
Removal deletes only this feature's owned model/temp folders and legacy stores. Saved WAV exports and unrelated settings/audio are preserved. The ONNX runtime ships as extension code; Chrome cannot delete those installed code files through this button. Browser-managed HTTP, compiled-WASM, GPU and filesystem metadata may remain.

  
Temporary song audio and stems — RAM

  
Separated stem windows live in each video frame's RAM. Temporary source downloads are stored in extension OPFS under ytbm-stems/videos/<video-id>-<safe-title>-<session>/ with video.json and either source.audio (complete retrieval) or source.audio.part (native buffered prefix). They are deleted on session cleanup and on the next extension-host start after an interruption. Manually exported WAV files are preserved.

  

  
Exported WAV files — disk

  
Only an explicit stem export creates WAV files. Look in chrome://downloads and use Show in Finder for the exact saved location. The usual macOS default is ~/Downloads/; a custom download setting can change it.
